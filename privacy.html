1. YouTube API Services の利用 / Use of YouTube API Services

本アプリ「バズワードch アップロード」は YouTube API Services を利用しています。本アプリを利用する方は、YouTube 利用規約に同意したものとみなされます。Google によるデータの扱いについては Google プライバシー ポリシーをご覧ください。

This app uses YouTube API Services. By using this app, you agree to be bound by the YouTube Terms of Service. Please also refer to the Google Privacy Policy (http://www.google.com/policies/privacy).

2. 利用者 / Who uses this app

本アプリは、YouTube チャンネル「バズワードch」の運営者本人だけが、自分の Google アカウントでログインして使う個人用のツールです。ほかの方は利用できません。

This app is used only by the owner of the YouTube channel "バズワードch", who signs in with their own Google account. No other users can access it.

3. アクセス・利用・保存する情報 / Information accessed, used and stored

  • Google の許可（OAuth 2.0）で得たアクセス用の情報（アクセストークン・リフレッシュトークン）：運営者の PC の中にだけ保存し、運営者自身のチャンネルへのアップロードにだけ使います。
    OAuth 2.0 access and refresh tokens are stored only on the owner's local PC and are used only to upload to the owner's own channel.
  • アップロードした動画の ID と URL：どの回を公開したかを記録するため、運営者の PC の中のファイルに保存します。
    The IDs and URLs of videos uploaded to the owner's own channel are stored in local files on the owner's PC to record what has been published.
  • ログインしたチャンネルの名前と ID：つないだ先が正しいかを確かめるために表示するだけで、保存しません。
    The authenticated channel's name and ID are only displayed to confirm the connection and are not stored.

本アプリは、ほかのユーザーやほかのチャンネルの情報を取得・保存しません。動画の視聴回数などの統計情報も保存しません。

This app does not collect or store any information about other users or other channels, and does not store statistics.

4. 第三者への提供 / Sharing

本アプリが扱う情報を、第三者に提供・販売・共有することはありません。情報は Google（YouTube）とのやり取りにだけ使います。

We do not share, sell or disclose any information to third parties. Information is exchanged only with Google (YouTube) through the YouTube API Services.

5. Cookie など / Cookies and similar technologies

本アプリ（PC で動くプログラム）は、利用者の端末に Cookie などを保存したり読み取ったりしません。このウェブサイトも Cookie を使いません。

This app does not store or read cookies or similar technologies on users' devices. This website does not use cookies.

6. 許可の取り消しと削除 / Revoking access and deletion

本アプリへの許可は、Google のセキュリティ設定ページ https://security.google.com/settings/security/permissions からいつでも取り消せます。取り消したとき、または下の連絡先に削除の依頼があったときは、PC に保存したアクセス用の情報を 7 日以内に削除します。保存しているアクセス用の情報は、最後に使ってから 30 日を超えて保存しません（使わなくなった場合は削除します）。

You can revoke this app's access at any time via the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, or on request to the contact below, stored tokens are deleted from the owner's PC within 7 days. Stored authorization data is not kept for more than 30 days after it was last used.

If this policy changes, this page will be updated together with the date above.
