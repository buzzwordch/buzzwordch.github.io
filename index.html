このアプリについて / About

「バズワードch アップロード」は、YouTube チャンネル「バズワードch」の運営者が、自分のチャンネルに動画を投稿するためだけに使う個人用のツールです。一般には提供していません。

運営者が内容を確認して公開を決めた動画（本編とショート）を、YouTube Data API を使って運営者自身のチャンネルにアップロードし、サムネイルの設定と公開日時の予約を行います。

Buzzword-ch Uploader is a private, single-user tool used only by the owner of the YouTube channel "バズワードch" (Buzzword-ch) to upload videos to the owner's own channel. It is not offered to the public. After the owner reviews and approves each finished video, the tool uploads the main video and its Short to the owner's channel with the YouTube Data API, sets the custom thumbnail, and schedules the publish time.

使っている YouTube の機能 / YouTube API features used

  • 動画のアップロード（videos.insert）・公開日時の予約 / Video upload and scheduled publishing
  • サムネイルの設定（thumbnails.set） / Custom thumbnail
  • 自分の動画の処理状況の確認（videos.list）・試しの動画の削除（videos.delete） / Checking the status of the owner's own uploads, deleting the owner's own test uploads
  • ログインしたチャンネルの確認（channels.list） / Confirming the authenticated channel
